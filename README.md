# OpenCode Agent — страница проекта

Статический сайт-визитка Telegram-агента OpenCode. Опубликован через GitHub Pages.

## Что здесь

- `index.html` — одностраничный сайт на русском языке.
- `styles.css` — адаптивные стили, тёмная тема, без внешних зависимостей.
- `script.js` — часы и копирование примеров запросов по клику.

Сайт не содержит токенов, ключей и приватных данных.

## Локальный просмотр

```bash
python -m http.server 8000
# http://localhost:8000
```

## Публикация

GitHub Pages включён на ветке `main`, корень репозитория. После pushChanges страница обновляется автоматически.
